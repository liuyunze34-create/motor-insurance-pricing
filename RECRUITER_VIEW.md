# Recruiter view

If you only have two minutes, start with these files:

- `README.md` — what the project does and the main results.
- `RESULTS.md` — short model-performance summary.
- `dashboard.html` — quick visual overview.
- `PORTFOLIO.md` — resume bullets and interview explanation.

For a technical review, continue with:

- `Motor_Insurance_Pricing.ipynb`
- `PROJECT_REPORT.md`
- `run_project.py`
- `project_utils.py`

The project is intentionally reproducible from OpenML rather than storing large raw source files in GitHub.
